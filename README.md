# Финансовый телеграм-бот

## Запуск

1. В Telegram открой @BotFather → `/newbot` → получи токен.
2. Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN=...`.
3. Установи зависимости и запусти:
   ```
   py -m pip install -r requirements.txt
   py bot.py
   ```
4. Напиши боту `/id`, впиши свой id в `ALLOWED_USER_ID` в `.env` и перезапусти — тогда бот будет отвечать только тебе.

Данные хранятся в `finance.db` рядом с ботом.

## Как пользоваться

| Сообщение | Что произойдёт |
|---|---|
| `500 еда` | расход 500, категория «еда» |
| `-1200 такси домой` | расход с комментарием |
| `+80000 зарплата` | доход |
| `/balance` | баланс |
| `/month`, `/week` | статистика по категориям |
| `/history` | последние 10 операций |
| `/undo`, `/del 12` | удалить операцию |
| `/budget еда 15000` | месячный лимит на категорию |
| `/budgets` | сколько осталось по лимитам |
| `/export` | выгрузка в CSV (открывается в Excel) |
